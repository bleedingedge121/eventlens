# Changelog

All notable changes to the EventLens project will be documented in this file.

## [0.1.0] - 2026-10-15
### Added
- Initial repository setup and professional project structure.
- Implementation of AGENTS.md team contract and ownership guidelines.
- Frozen API contract specifications for HackHive PS-3.
- SQLite database schema definition (`data/events.db`).
- Configuration templates for camera zones (`config/cameras.json`) and system settings (`config/settings.json`).
- Mock events dataset for frontend rapid prototyping (`backend/server/mock_events.json`).
- Environment validation script (`scripts/check_env.py`).
- Automated setup and model download scripts (`scripts/setup.ps1`, `scripts/download_models.ps1`).
